# Proyecto: Instalación de Cámaras de Videovigilancia y Servicio Social en el CETis 127

## Descripción
Este proyecto documenta la instalación de un sistema de cámaras de videovigilancia y el trabajo realizado durante el servicio social en el taller de soporte técnico del CETis No. 127.  
El objetivo principal fue mejorar la seguridad, el mantenimiento y la infraestructura tecnológica del plantel.

## Tecnologías y Herramientas
Cableado estructurado UTP Cat6, DVR, Cámaras IP, Monitores, Herramientas de red, Configuración IP, Montaje técnico.

## Archivos del proyecto
- `Informe_Instalacion_Camaras_CETIS127.pdf`: Detalla el proceso completo de instalación y configuración del sistema de videovigilancia.  
- `Reporte_Final_Servicio_Social.pdf`: Resume las actividades, aprendizajes y conclusiones del servicio social.  
- Carpeta `imagenes/`: Contiene evidencias visuales del proceso.

## Objetivo general
Implementar un sistema de seguridad mediante cámaras de videovigilancia y fortalecer la infraestructura de red en el CETis 127, garantizando un entorno más seguro y tecnológicamente eficiente.

## Resultados
- Instalación exitosa de cámaras en zonas estratégicas.  
- Red funcional y organizada con cableado estructurado.  
- Sistema operativo de grabación y monitoreo en tiempo real.  
- Aprendizaje técnico y práctico durante el servicio social.
